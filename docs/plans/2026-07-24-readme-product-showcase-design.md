# README 中文产品图册设计

## 目标

将 README 当前两张英文旧截图替换为一套完整、可信、可维护的中文产品图册。图册以 AgentHub 已有路由、组件和功能文档为依据，使用演示数据呈现典型状态，不把尚未实现的 Provider 或产品能力画入界面。

## 展示范围

图册包含 16 组页面：

1. 欢迎与创建账户
2. 设备授权与账户恢复
3. 设备仪表盘与设备详情
4. 会话工作台
5. 新建会话
6. AI 对话
7. 工具调用与权限审批
8. 文件管理器
9. 下载管理
10. Git 工作区
11. Git 提交树
12. 加密 Artifacts
13. 安全外部分享
14. 使用情况
15. 设置与凭据
16. 版本亮点与更新

## 视觉规范

- 每个原始页面截图为 1080 × 2338，保持现有 390 × 844 移动端长屏比例。
- 同一页面分别输出 Amber Crystal 深色主题和 Amber Crystal Light 浅色主题。
- 最终 README 展示图使用正面手机模型承载原始截图，成品为 1080 × 2338。
- 手机模型使用低饱和银灰金属边框、中性浅灰背景和柔和灰色落影，不使用金色边框或彩色外发光；界面内容通过 HTML/CSS 确定性渲染后再合成，避免中文或代码文本失真。
- 使用思源黑体、文泉驿正黑和等宽字体，确保中文及代码路径清晰。
- 保持 AgentHub 现有石墨黑、雾白、琥珀强调色、玻璃表面、细边框和紧凑开发工具信息密度。
- 图上明确标记“演示数据”，避免将示例账号、设备、版本和代码仓库误解为真实运行数据。
- 页面主体呈现功能本身；README 文案负责解释亮点，不在截图上叠加夸张营销标注。

## 演示数据原则

- 设备、目录和分支使用稳定的虚构名称，例如“上海开发机”“AgentHub”“feature/session-workbench”。
- 会话仅展示当前支持的 Claude Code 和 Codex。
- 对话页面包含 Markdown、任务进度、上下文用量、文件引用和思考状态。
- 工具页面包含命令执行、文件编辑、Diff、权限审批和会话级授权。
- 下载页面展示进行中、暂停、完成和失败重试状态。
- Git 页面展示暂存/未暂存、增删行、提交信息、分支、标签和合并节点。
- 安全页面展示端到端加密、客户端解密、有效期和撤销，不展示真实密钥。

## 生成与维护

`scripts/readme-showcase/mobile.html` 是界面图事实源。`design/phone.png` 是已经清除绿色屏幕、带透明开口的银灰手机覆盖层；`composite.html` 在浏览器中把每个 HTML/CSS 产品页面放到透明屏幕下方，并由无头 Chrome 完成最终截图。`scripts/readme-showcase/generate.sh` 负责逐页、逐主题执行这一流程。原图写入 `docs/assets/readme/showcase/screens/`，手机模型成品写入 `docs/assets/readme/showcase/phones/`。32 张页面内容和最终合成都不由生图工具生成。
